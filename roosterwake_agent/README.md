# Rooster Wake agent

The free [Rooster Wake](https://roosterwake.com) agent as your account's **always-on waker**,
on the Home Assistant box that is already always on. It sends the Wake-on-LAN packet to the
machines on this network when you press Wake anywhere — and it is free on every plan.

Give it your account address (or an enrolment token from the dashboard's Emitters page) in the
Configuration tab, start it, and within a minute it is on your Emitters page as an **Always on**
waker. See the **Documentation** tab for the options, the networking note and the difference
between this add-on and the integration in the same repository.
